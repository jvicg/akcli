# akcli

Command-line interface to make requests to Akamai API.

#### Installation

=== "pip"
    ```bash title="install" linenums="1" hl_lines="1-2"
    pip install akcli
    ```

=== "pipx"
    ```bash
    pipx install akcli
    ```

#### Quick start

```bash
akcli --help
```

??? tip "This is collapsable because of the '???'"
    Run `akcli --init-config-file` to generate a config file with all the default values. This way you can customize the CLI behavior without passing flags every time.
